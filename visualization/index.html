Enumerated sets and selector calculation

Every independent set in the join stays on one side. The empty set occurs on both sides, so the two counts sum with one subtracted.

The edge formula plus four forced-false variables has ten variables. Its probability is the joined count divided by 1,024, to be compared with 1/128. Akmal’s selector averages that probability with 127/128. The resulting fraction is compared with one half, with equality accepted.
