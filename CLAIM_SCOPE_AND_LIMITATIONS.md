# Claim scope

The 3-CNF base has clause width at most three. The input permits one additional clause with any width. The model uses independent uniform assignments and accepts ties. The 2-CNF comparison uses an input positive exponent. It can be encoded in binary. Every reduction proving hardness is polynomial-time many-one.

The source threshold uses general graphs. The finite computations illustrate the reductions. The bounded priority check and internal review are described in the audit summaries.
